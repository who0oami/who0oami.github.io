작은 카페 앱의
주문하는 흐름.

React Native 소스의 메뉴 데이터·색상·화면 구성을 웹에서 재현했습니다. 카드를 누르거나 장바구니 수량을 조절해 보세요.

미리보기 사용법
① 메뉴 카드 선택 → 상세
② 수량 선택 → 장바구니
③ 담은 메뉴 수정 또는 삭제
④ 새로고침 후 장바구니 확인
⑤ 주문 확인 → 확정 → 주문 내역 조회

브라우저 시연용 화면입니다. 장바구니와 데모 주문 내역은 브라우저 localStorage에 저장됩니다. 실제 주문·결제·서버 DB는 사용하지 않습니다.
